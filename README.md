# 벅스·바이브 곡명 자동 검색 / 원클릭 링크 생성 웹사이트

PC나 모바일 브라우저에서 곡명만 입력해 서비스별 곡을 검색하고 ID를 확인한 후 원클릭 링크를 만드는 웹사이트입니다.

## 사용하기

1. 곡명 또는 `곡명 | 아티스트` 형식으로 한 줄에 한 곡을 입력합니다.
2. 벅스·바이브 체크 후 **곡 자동 검색**을 선택합니다.
3. 동명이곡 및 리믹스 등 검색 결과가 올바른지 확인합니다.
4. **원클릭 링크 생성**을 누릅니다.
5. 재생할 플랫폼의 링크를 복사·공유합니다.

## 공개 웹주소 만들기

이 파일들은 바로 공개된 웹주소가 아닙니다. 서버 호스팅 서비스에 배포해야 합니다.

### Replit (간편)
1. Replit에 계정을 만들고 Python 프로젝트를 만듭니다.
2. ZIP에서 `server.py`, `index.html`, `.replit` 파일을 프로젝트 최상단에 업로드합니다.
3. Run을 누르고 웹 미리보기에서 `/api/health`에 `ok: true`가 뜨는지 확인합니다.
4. Deploy/Publish 메뉴로 공개 주소를 발급합니다. 요금 및 배포 권한은 Replit 정책을 확인하세요.

### Render (GitHub 연결)
1. 이 폴더의 파일을 GitHub 저장소 루트에 올립니다.
2. Render에서 **New → Blueprint**를 선택하고 저장소를 연결합니다.
3. `render.yaml` 구성을 확인하고 배포합니다.
4. 배포된 Render URL에서 곡명을 입력해 확인합니다.

## 직접 로컬에서 확인하기 (선택)

Python 3가 있는 PC에서 `python server.py --hosted` 실행 후 `http://127.0.0.1:8000/`을 열 수 있습니다.

## 주의 사항

- 링크 생성은 무료이나 실제 음악 감상에는 각 플랫폼 앱 및 서비스 이용 권한이 필요합니다.
- 곡명 자동 검색은 벅스의 검색 화면과 바이브의 비공식 웹 API에 의존합니다. 응답 구조 변경이나 접속 제한 시 검색이 실패할 수 있습니다.
- 현재 검색 및 앱 딥링크 재생은 실제 플랫폼 서버/모바일 환경에서 끝까지 검증한 상태가 아닙니다.
- 이 도구는 음원을 재생하지 않으며 스트리밍 횟수를 보장하지 않습니다.
- 검색 데이터(곡명·아티스트)는 검색 대상 서비스에 전달되며, 사용자의 곡 목록은 브라우저 저장소에 보존됩니다.
- 바이브(VIBE)는 2026년 12월 31일 서비스 종료 예정으로 공식 안내되었습니다.
